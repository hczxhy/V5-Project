## Installation
To install the project, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/hczxhy/V5-Project.git
   ```
2. Navigate to the project directory:
   ```bash
   cd V5-Project
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

## Usage
To run the project, use:
```bash
npm start
```
